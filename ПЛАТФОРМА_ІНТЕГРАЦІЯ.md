## 1. Загальна схема роботи

```
PHP Platform (content.fineko.space)         FINEKO Flows              Мікросервіси
     │                                           │                          │
     │  POST flows.fineko.space/webhook/bot/<slug>                          │
     │──────────────────────────────────────────>│                          │
     │  {postId, mediaInput, callbackUrl}         │                          │
     │                                           │  img.flows.fineko.space  │
     │                                           │─────────────────────────>│
     │                                           │  slides.flows.fineko.space
     │                                           │─────────────────────────>│
     │                                           │  video.flows.fineko.space
     │                                           │─────────────────────────>│
     │                                           │<─────────────────────────│
     │  POST /api/generation/webhook?post_id=&token=                        │
     │<──────────────────────────────────────────│                          │
     │  {postId, status, imageBase64|slidesBase64|videoPath}                │
```

**Принцип**: платформа ініціює генерацію → воронка обробляє → результат повертається через `callbackUrl`.

## 2. База даних платформи

Таблиця `posts` вже має всі потрібні колонки (перевірено на `fineko.mysql.tools`):

| Колонка | Тип | Призначення |
|---|---|---|
| `generation_status` | varchar | `not_generated` / `queued` / `processing` / `ready` / `failed` |
| `generation_job_id` | varchar | ID завдання від воронки |
| `generation_flow_key` | varchar | Назва воронки (`content-stories-generator` тощо) |
| `generation_output_url` | text | URL готового медіа (або JSON-масив URL для каруселі) |
| `generation_error` | text | Текст помилки |
| `generation_requested_at` | datetime | Час старту |
| `generation_finished_at` | datetime | Час завершення |
| `avatar_engine` | varchar | `heygen` або `liveportrait` |
| `image_path` | text | Також оновлюється готовим URL (дублюється) |

Якщо якась колонка відсутня — `MediaGenerationService` обходить через `hasColumn()` і не падає.

Таблиця `settings` — зберігає per-project налаштування, зокрема `brand_handle`:
```sql
SELECT setting_value FROM settings WHERE project_id = ? AND setting_key = 'brand_handle';
```

## 3. HTTP-маршрути платформи (реалізовано)

### 3.1 Запуск генерації — через `MediaGenerationService`

Клас `php-mvc/app/core/MediaGenerationService.php` відповідає за весь цикл.

Виклик з контролера:
```php
$service = new MediaGenerationService($db, $mcpConfig);
$result  = $service->startForPost($postId, $projectId, $avatarEngine);
// $result: ['ok'=>true, 'post_id'=>42, 'status'=>'processing', 'job_id'=>'...', 'flow'=>'content-stories-generator']
```

### 3.2 Callback-endpoint від воронок (РЕАЛІЗОВАНО)

**URL:** `POST https://content.fineko.space/api/generation/webhook?post_id={id}&token={token}`

**Token** з `mcp.php` → `generation_webhook_token`: `fnk_wh_2026_x9mK4pLqR7vNsT1eYcJdBuAw`

Обробник: `MediaGenerationService::handleWebhook($postId, $payload)`

**Логіка обробки:**
- `imageBase64` → декодує → `public/uploads/generated/post_{id}.png` → URL у `generation_output_url`
- `slidesBase64[]` → зберігає кожен → JSON-масив URL у `generation_output_url`
- `videoPath` (локальний на VPS) → копіює до `public/uploads/generated/post_{id}_video.mp4`
- `status` → маппінг у `generation_status` таблиці `posts`

### 4.3 Розумний монтаж + базові субтитри
`slug: content-video-basic-subs`

**Webhook request:**
```json

  "postId": "42",
  "videoUrl": "https://content.fineko.space/uploads/video.mp4",
  "callbackUrl": "https://content.fineko.space/api/generation/webhook?post_id={postId}&token=fnk_wh_2026_x9mK4pLqR7vNsT1eYcJdBuAw"
}
```

**Callback:**
```json
{
  "postId": "42",
  "status": "success",
  "mediaType": "video",
  "videoPath": "/var/www/video.flows.fineko.space/tmp/job123/output.mp4",
  "transcript": {
    "text": "Транскрипція всього відео",
    "words": [{"word": "Привіт", "start": 0.1, "end": 0.4}]
  }
}
```

> **Phase 1 обмеження**: `videoPath` — локальний шлях на VPS. PHP-платформа на shared hosting не може його читати.
> **Рішення для Phase 1**: video.flows.fineko.space виставляє `/content/uuid.mp4` через Nginx — платформа завантажує по URL.
> **Phase 2**: поле стане `videoUrl` з публічним URL.

**Що робить воронка:**
1. Транскрибує відео (Whisper)
2. Claude знаходить паузи > 0.5с і слова-паразити
3. FFmpeg вирізає ці сегменти
4. FFmpeg запікає субтитри (SRT)

**Підходить для:** TikTok, Instagram Reels, YouTube Shorts, Facebook Reels.

**Перший callback (миттєво, від воронки):**
```json
{
  "postId": "42",
  "status": "queued",
  "mediaType": "video",
  "jobId": "remotion-abc123",
  "estimatedSec": 120
}
```

**Другий callback (~2 хв, від Remotion-renderer напряму на `callbackUrl`):**

**Підходить для:** Premium Reels/TikTok — анімовані karaoke-титри (слово підсвічується/збільшується).

## 5. Логіка вибору воронки на платформі

```php
function selectFunnel(Post $post, string $socialNetwork): ?string
{
    // Тип поста визначає воронку
    switch ($post->content_type) {
        case 'story':
            return 'content-stories-generator'; // для всіх мереж

        case 'carousel':
            return 'content-carousel'; // Instagram, Facebook, LinkedIn

        case 'video':
            // Якщо вже є готове відео — тільки адаптація
            if ($post->source_video_url) {
                if (in_array($socialNetwork, ['tiktok', 'youtube'])) {
                    return 'content-resizer';
                }
                return $post->karaoke_subtitles
                    ? 'content-video-remotion'
                    : 'content-video-basic-subs';
            }
            return null;

        case 'feed':
            return 'content-feed-post'; // ще не створена, Phase 2
    }

    return null;
}
```

## 7. Архітектура зберігання медіа

### Phase 1 — Shared Hosting (поточний стан)

| Тип | Що повертає воронка | Що робить платформа |
|-----|--------------------|--------------------|
| Зображення | `imageBase64` | Декодує base64, зберігає у `uploads/generated/{postId}.png` |
| Карусель | `slidesBase64[]` | Декодує кожен, зберігає N файлів |
| Відео | `videoPath` (локальний шлях) | ❌ Не може прочитати з shared hosting |

**Тимчасове рішення для відео**: відео-мікросервіс виставляє готовий файл через Nginx:
- `https://video.flows.fineko.space/content/{uuid}.mp4`
- Платформа завантажує по HTTP і зберігає локально

### Phase 2 — Після переїзду на VPS

Мікросервіси зберігають результат у публічній директорії і повертають URL:

```
img.flows.fineko.space/generated/{uuid}.png
video.flows.fineko.space/content/{uuid}.mp4
```

**Нові endpoints мікросервісів:**
- `POST https://img.flows.fineko.space/upload` → `{"params":{"imageBase64":"...","filename":"..."}}` → `{"result":{"publicUrl":"https://img.flows.fineko.space/generated/uuid.png"}}`
- `POST https://video.flows.fineko.space/publish` → `{"params":{"videoPath":"/tmp/...","filename":"..."}}` → `{"result":{"publicUrl":"https://video.flows.fineko.space/content/uuid.mp4"}}`

Після додавання цих endpoints у воронки вставляються проміжні httpRequest-ноди перед callback.

**Альтернатива**: Cloudflare R2 (env vars вже налаштовані у всіх воронках: `R2_BUCKET`, `R2_ACCOUNT_ID`, `R2_API_TOKEN`, `R2_PUBLIC_URL`).

## 8. Безпека callback-endpoint (реалізовано)

Callback-URL вже містить токен у query-параметрі:
```
https://content.fineko.space/api/generation/webhook?post_id={id}&token=fnk_wh_2026_x9mK4pLqR7vNsT1eYcJdBuAw
```

Перевірка на платформі: `MediaGenerationService::isValidWebhookToken($incomingToken)` через `hash_equals`.  
Токен зберігається у `php-mvc/config/mcp.php` → `generation_webhook_token` (файл у `.gitignore`, є на сервері).

Якщо потрібно змінити токен — оновити `mcp.php` на сервері і відповідно оновити `callbackUrl` у воронках через MCP.

## 9. Приклад повного циклу (сторі для Instagram)

1. Менеджер у платформі створює пост: текст + фото + тип `story` + мережа `instagram`
2. Платформа відправляє (`MediaGenerationService::startForPost(101)`):
   ```
   POST https://flows.fineko.space/webhook/bot/content-stories-generator
   {
     "postId": "101",
     "photoUrl": "https://content.fineko.space/uploads/images/photo.jpg",
     "text": "5 помилок при веденні Cashflow",
     "subText": "Розбираємо на прикладі",
     "brandHandle": "@fineko",
     "template": "default",
     "callbackUrl": "https://content.fineko.space/api/generation/webhook?post_id=101&token=fnk_wh_2026_x9mK4pLqR7vNsT1eYcJdBuAw"
   }
   ```
   → DB: `posts.generation_status = processing`, `generation_flow_key = content-stories-generator`
3. Воронка: remove-bg (img.flows.fineko.space) → render/story (slides.flows.fineko.space) → POST callbackUrl
4. Платформа отримує callback на `/api/generation/webhook?post_id=101&token=...`:
   ```json
   {"postId":"101","status":"success","mediaType":"image","imageBase64":"iVBORw0KGgo..."}
   ```
5. `handleWebhook()` декодує base64 → `public/uploads/generated/post_101.png`  
   → DB: `generation_status = ready`, `generation_output_url = https://content.fineko.space/uploads/generated/post_101.png`
6. Cron `daily-posts` бачить `generation_status = ready` → використовує `generation_output_url` для публікації
