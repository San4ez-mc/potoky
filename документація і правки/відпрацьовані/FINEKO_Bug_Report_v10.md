## BUG-001 · `get_connector` не повертає збережені екземпляри

**Статус:** Відкритий  
**Пріоритет:** Середній  
**Виявлено при:** Перебудова Bot 1.1 Onboarding

**Опис:**  
`get_connector` і `list_connectors` повертають тільки *визначення типу* конектора. Не повертають збережені екземпляри з налаштованими ключами.

**Пропонована зміна відповіді `get_connector`:**
```json
{
  "id": "ad7582d3-...",
  "name": "Claude Haiku",
  "type": "claude_haiku",
  "schema": { "..." },
  "instances": [
    {
      "id": "inst_abc123",
      "label": "Haiku — Finance Course",
      "has_keys": true,
      "keys_configured": ["api_key"]
    }
  ]
}
```

## BUG-003 · `claude`-нода не підтримує багатокроковий діалог

**Статус:** Відкритий  
**Пріоритет:** Критичний  
**Виявлено при:** Тестування Bot 1.1

**Опис:**  
Зараз `claude`-нода працює тільки як одноразовий виклик: надіслала одну відповідь → передала управління далі. Більшість ботів курсу потребують повноцінного діалогу де студент відповідає кілька разів.

**Пропозиція: параметр `mode` в claude-ноді (бекенд)**

### `mode: "single"` (поточна поведінка, за замовчуванням)
Один виклик → результат в `outputVar` → наступна нода.

```json
{
  "type": "claude",
  "data": {
    "mode": "single",
    "systemPrompt": "...",
    "outputVar": "context.result"
  }
}
```

### `mode: "dialog"` (новий режим)
Нода залишається активною. Кожне повідомлення студента → виклик Claude з `conversationHistory` → відповідь → чекати. Вихід тільки при `exitCondition`.

```json
{
  "type": "claude",
  "data": {
    "mode": "dialog",
    "systemPrompt": "...",
    "outputVar": "context.result",
    "exitCondition": "json_output"
  }
}
```

**Підтримувані значення `exitCondition`:**

| Значення | Умова виходу |
|----------|--------------|
| `"json_output"` | Відповідь Claude є валідним JSON → зберегти в `outputVar` → перейти далі |
| `"keyword: DONE"` | Відповідь містить вказане ключове слово (налаштовується) |
| `"user_confirms"` | Студент написав «так / вірно / ок / гаразд» → Claude робить фінальний виклик → перейти далі |
| `"markdown_output"` | Відповідь Claude містить Markdown-блок (``` або # заголовок) |

**Логіка виходу при `json_output`:**
```
1. Claude відповідає
2. Runtime перевіряє: чи є у відповіді валідний JSON?
3. Якщо так → парсить JSON, записує в outputVar → наступна нода
4. Якщо ні → відправляє відповідь студенту, чекає наступного повідомлення
```

**Яких ботів курсу стосується:**

| Бот | mode | exitCondition |
|-----|------|---------------|
| 1.1 Onboarding | `dialog` | `json_output` |
| 1.2 Business Process | `dialog` | `json_output` |
| 2.1 Articles | `dialog` | `json_output` |
| 3.3 Diagnostics | `dialog` | `markdown_output` |
| Всі інші з claude-нодою | потребує перевірки після реалізації | — |

## BUG-004 · `saveFile` зберігає неправильне значення змінної

**Статус:** Відкритий  
**Пріоритет:** Високий  
**Залежить від:** BUG-003

**Симптоми:**  
`saveFile` з `contentVar: "context.onboarding_result"` зберегла перше питання Claude замість фінального JSON. Є наслідком BUG-003 — діалог не дійшов до генерації JSON. Після фіксу BUG-003 перевірити окремо.

## FEATURE-001 · Фронтенд — UI для `mode` і `exitCondition` в Claude Node

**Статус:** Відкритий  
**Пріоритет:** Високий  
**Залежить від:** BUG-003 (бекенд має підтримати параметри першим)

**Опис:**  
Після реалізації BUG-003 на бекенді — налаштування ноди у візуальному редакторі мають відображати нові параметри. Зараз панель «Налаштування ноди» для Claude Node містить тільки «Назва вузла» і «System Prompt» (підтверджено скріншотом).

**Що додати в панель налаштувань Claude Node:**

### 1. Поле «Тип запиту» (параметр `mode`)

Випадаючий список (select) з двома опціями:

```
[ Одиночний запит  ▾ ]   ← mode: "single"
[ Діалог           ▾ ]   ← mode: "dialog"
```

- Підпис: **Тип запиту до ШІ**
- За замовчуванням: «Одиночний запит»
- Підказка (tooltip або subtext): «Одиночний — один виклик і далі. Діалог — бот спілкується зі студентом поки не виконається умова виходу.»

---

### 2. Поле «Умова завершення діалогу» (параметр `exitCondition`)

З'являється тільки коли обрано `mode: "dialog"`. Випадаючий список:

```
[ JSON у відповіді          ▾ ]   ← "json_output"
[ Markdown у відповіді      ▾ ]   ← "markdown_output"
[ Підтвердження користувача ▾ ]   ← "user_confirms"
[ Ключове слово             ▾ ]   ← "keyword: ..."
```

Якщо обрано «Ключове слово» — з'являється текстове поле для введення слова.

- Підпис: **Умова завершення діалогу**
- Підказка: «Коли ця умова виконається — бот збереже результат і перейде до наступного кроку.»
