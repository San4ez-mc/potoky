## BUG-009 · Нові типи нод відображаються як білий квадрат у канвасі

**Статус:** Закрито  
**Пріоритет:** Середній  
**Виявлено при:** Перегляд Bot 2.1 після додавання `generateDocument` ноди

**Симптоми:**  
Нода типу `generateDocument` відображається в канвасі як білий порожній квадрат без підпису, іконки і кольору. Функціонально нода є і підключена правильно, але UI її не розпізнає.

**Причина:**  
Фронтенд не знає як рендерити нові типи нод — відсутні рендерери у канвасі.

**Що зроблено:**  
- Додано рендерери в `NODE_TYPES` для нових типів нод у `NodeTypes.jsx`.
- Додано елементи в `NODE_PALETTE` для створення цих нод через UI.
- Перевірено, що ноди рендеряться коректно (не білим квадратом), мають іконку, колір та підзаголовки.

| Тип ноди | Іконка | Колір | Підзаголовок |
|----------|--------|-------|--------------|
| `generateDocument` | 📄 | зелений | `data.template`, `data.sourceVar` |
| `sendPhoto` | 📸 | рожевий | `data.caption` |
| `sendDocument` | 📎 | фіолетовий | `data.fileKey` |
| `httpEncode` | 🔒 | блакитний | `data.sourceVar` |
| `fetchTelegramProfile` | 👤 | блакитний | — |
| `notifyAdmin` | 📣 | помаранчевий | `data.telegramId` |
| `wait` | ⏳ | сірий | `data.duration` |
| `condition` | 🔀 | помаранчевий | `data.condition` |
| `loadFile` | 📂 | зелений | `data.fileType` (вже є, перевірити) |

## BUG-010 · На сторінці "Воронки" порожній список через INTERNAL_ERROR API

**Статус:** Закрито (hotfix на production)  
**Пріоритет:** Високий  
**Виявлено при:** Відкриття `/funnels` після деплою v11

**Симптоми:**  
- UI показує `Немає воронок за обраним фільтром`.
- У Network для запиту списку ботів: `ok: false`, `error.code: INTERNAL_ERROR`.

**Технічна причина:**  
- API маршрут `GET /api/projects/:id/bots` падав на `prisma.bot.findMany()`.
- У production БД не була застосована міграція з полями `bots.goal` та `bots.outputFiles`.
- Додатково: первинна спроба SQL в одному `psql -c` (з `ALTER TABLE` + некоректним `CREATE INDEX`) відкотила всю транзакцію.

**Що зроблено:**  
- На production застосовано окремими командами:
	- `ALTER TABLE bots ADD COLUMN IF NOT EXISTS goal TEXT NULL;`
	- `ALTER TABLE bots ADD COLUMN IF NOT EXISTS "outputFiles" TEXT NULL;`
- Перевірено структуру таблиці `bots` після змін.
- Перевірено endpoint `GET /api/projects/:id/bots` — повертає `ok: true` і повний список воронок.

**Профілактика на наступні деплої:**
1. Міграції запускати перед smoke-перевіркою UI.
2. Не поєднувати критичні DDL-операції в один `psql -c` без перевірки.
3. Після деплою обов'язково перевіряти:
	 - `GET /api/projects`
	 - `GET /api/projects/:id/bots`
	 - Відкриття `/funnels` у браузері.
