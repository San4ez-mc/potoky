## BUG-004 — розбити `mcp-flows.js` на два окремі MCP сервери

**Статус:** ✅ Реалізовано (13.05.2026)  
**Пріоритет:** P1

**Причина:** При 16 інструментах в одному MCP сервері векторний пошук Claude.ai стабільно витісняє частину інструментів. `new_bot` не підтягується жодним запитом незалежно від назви та опису.

### Архітектура після розбивки

**Поточний стан:** 1 сервер × 16 інструментів  
**Цільовий стан:** 2 сервери × ~6-10 інструментів кожен

### Сервер 1 — FINEKO flows (читання + навігація)

**URL:** `https://flows.fineko.space/api/mcp` (існуючий)  
**Файл:** `mcp-flows.js` (скорочується)  
**Інструменти (6):**

| Інструмент | Опис |
|---|---|
| `list_funnels` | Список всіх ботів |
| `get_funnel` | Повна воронка по botId |
| `get_node_stats` | Статистика ноди |
| `get_api_logs` | Логи API викликів |
| `list_connectors` | Список конекторів |
| `get_connector` | Конектор по id або type |

### Сервер 2 — FINEKO flows edit (запис + зміни)

**URL:** `https://flows.fineko.space/api/mcp-edit` (новий)  
**Файл:** `mcp-flows-edit.js` (новий)  
**Інструменти (10):**

| Інструмент | Опис |
|---|---|
| `new_bot` | Створити нового бота з порожньою FlowDefinition |
| `add_node` | Додати ноду до воронки |
| `update_node` | Оновити дані ноди |
| `delete_node` | Видалити ноду і всі її edges |
| `create_edge` | Створити edge між нодами |
| `update_funnel_key` | Створити або оновити ключ воронки |
| `delete_funnel_key` | Видалити ключ воронки |
| `create_connector` | Створити новий конектор |
| `update_connector` | Оновити конектор |
| `delete_connector` | Видалити конектор |

### Що треба зробити (код)

**1. Створити `mcp-flows-edit.js`** — скопіювати структуру з `mcp-flows.js`, залишити тільки інструменти Сервера 2. Логіку не переписувати — імпортувати `callTool` з `tools-flows.js` як є.

**2. Зареєструвати новий роут:**
```javascript
const mcpFlowsEdit = require('./routes/mcp-flows-edit');
app.use('/api/mcp-edit', mcpFlowsEdit);
```

**3. Скоротити `mcp-flows.js`** — прибрати всі інструменти що переїхали в edit.

**4. `tools-flows.js` — не чіпати.** Обидва сервери імпортують `callTool` з одного файлу.

**5. Автентифікація** — та сама схема (Bearer token / mcpToken).

## UI-002 — Сторінка "Збережені конектори" → рефакторинг

**Статус:** ✅ Реалізовано (13.05.2026)  
**Пріоритет:** P2

### Термінологія (важливо)

| Термін | Що це | Приклад |
|---|---|---|
| **Тип конектора** | Шаблон інтеграції: endpoint, документація, список полів для заповнення | "Claude Sonnet" — містить URL API, опис, поле для API ключа |
| **Збережений конектор** | Екземпляр типу з заповненими ключами конкретного користувача | "Sonnet основний" і "Sonnet додатковий" — один тип, два різних ключі |

### Поточні проблеми (зі скріншоту)

1. **Баги верстки** — обрізається перша літера заголовків: "онектори", "оступні типи конекторів", "бережені конектори" — очевидно CSS clip або overflow issue
2. **Немає CRUD** — не можна додати, редагувати або видалити збережений конектор
3. **Порожні типи** — секція "Доступні типи конекторів" порожня, бо не запущено seed
4. **Назва** — "Збережені конектори" незрозуміла без контексту

### Що змінити

**1. Перейменувати пункт меню:** "Збережені конектори" → **"Конектори"**

**2. Виправити баги верстки** — заголовки обрізаються, потрібно перевірити CSS `overflow: hidden` або `padding-left` на контейнері секцій

**3. Структура сторінки після рефакторингу:**

```
Конектори
│
├── [Вкладка] Типи конекторів
│   Системні шаблони — описують як підключитись до сервісу
│   
│   Картка типу:
│   ┌──────────────────────────────┐
│   │ 🤖 Claude Sonnet             │
│   │ Anthropic API для генерації  │
│   │ Поля: endpoint, API key      │
│   │              [+ Зберегти]    │
│   └──────────────────────────────┘
│
└── [Вкладка] Мої конектори           [+ Додати конектор]
    Екземпляри з заповненими ключами
    
    Картка збереженого конектора:
    ┌──────────────────────────────────────┐
    │ Sonnet основний                      │
    │ Тип: Claude Sonnet  ● Активний       │
    │                  [Редагувати] [🗑]   │
    └──────────────────────────────────────┘
```

**4. Форма додавання/редагування збереженого конектора:**
```
Назва:   [Sonnet основний          ]
Тип:     [Claude Sonnet         ▾  ]
─── Поля типу ──────────────────────
API Key: [sk-ant-...             🔒]
────────────────────────────────────
         [Скасувати]  [Зберегти]
```

**5. Запустити seed для типів конекторів:**
```bash
yarn seed:connector-defs
```
Після цього в "Типи конекторів" з'являться системні шаблони.
