## BUG-001 · FINEKO flows API — `get_connector` не повертає збережені екземпляри

**Статус:** Відкритий  
**Пріоритет:** Середній  
**Виявлено при:** Перебудова Bot 1.1 Onboarding

**Опис:**  
`get_connector` (і `list_connectors`) повертають тільки *визначення типу* конектора — схему, опис, іконку. Але не повертають збережені екземпляри цього конектора, де вже налаштовані ключі. Через це неможливо через MCP/API вибрати існуючий налаштований конектор і підключити його до ноди.

**Очікувана поведінка:**  
У відповіді `get_connector` (або `list_connectors`) поруч з визначенням типу додати масив `instances` — збережені екземпляри цього конектора що належать поточному акаунту. Секретні значення не передавати — тільки назви (label) і id.

**Пропонована зміна відповіді `get_connector`:**
```json
{
  "id": "ad7582d3-c314-4100-a934-b419d39f8dd5",
  "name": "Claude Haiku",
  "type": "claude_haiku",
  "schema": { ... },
  "instances": [
    {
      "id": "inst_abc123",
      "label": "Haiku — Finance Course",
      "has_keys": true,
      "keys_configured": ["api_key"]
    },
    {
      "id": "inst_def456",
      "label": "Haiku — Test Project",
      "has_keys": true,
      "keys_configured": ["api_key"]
    }
  ]
}
```

**Сценарій використання (AI-агент через MCP):**
1. Агент викликає `get_connector(type="claude_haiku")`
2. Бачить `instances` — є вже налаштований екземпляр "Haiku — Finance Course"
3. Запитує користувача: «Використати існуючий екземпляр чи введеш нові ключі?»
4. Підключає ноду через `instance_id` — секрети не гуляють по API взагалі

## BUG-002 · Bot 1.1 — Telegram keys підтягнулись з невідомого джерела

**Статус:** Потребує уточнення  
**Пріоритет:** Низький  
**Виявлено при:** Фінальна перевірка воронки Bot 1.1

**Опис:**  
Після перебудови воронки Bot 1.1 у `keys` з'явились `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `FUNNEL_CHANNELS` — хоча на початку сесії `keysCount: 0`. Можливо вони підтягнулись з іншого бота (1.2 використовує `fineko_processes_bot`), або це загальні ключі проекту.

**Очікувана поведінка:**  
Зрозуміти звідки беруться ключі — вони per-bot чи є спільні project-level keys? Якщо спільні — задокументувати в системі, щоб агент розумів звідки що береться.
