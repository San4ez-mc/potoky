# Skills / Правила роботи

Цей файл фіксує наші робочі правила. Доповнюємо його поступово.

## 1) Деплой

- Деплой робимо тільки через git.
- Базовий флоу:
  1. `git add ...`
  2. `git commit -m "..."`
  3. `git push origin main`
- Вважаємо деплой успішним тільки коли вивід містить `main -> main`.
- Прямі заливки файлів на сервер (`scp`, ручне копіювання) не використовуємо як стандартний шлях деплою.
- Після важливих змін у БД окремо проговорюємо і виконуємо міграції на проді.

## 2) Подальше розширення

- Нові правила додаємо в цей файл окремими секціями.
- Якщо правило змінилося, оновлюємо існуючий пункт, а не дублюємо.
